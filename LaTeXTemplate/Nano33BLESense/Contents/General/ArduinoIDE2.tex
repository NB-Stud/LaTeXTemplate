\section{Beschreibung der Arduino IDE}\label{ArduinoIDE}

Die Arduino IDE ist eine Open-Source-Software, die speziell für das Bearbeiten, Kompilieren und Hochladen von Code auf Arduino-Module entwickelt wurde. Sie ist plattformübergreifend und mit Betriebssystemen wie Windows, Linux und macOS kompatibel. Auf der Java-Plattform aufbauend unterstützt die IDE verschiedene Arduino-Module und die Programmierung in C und C++.

Die Mikrocontroller auf den Arduino-Boards werden so programmiert, dass sie die in Form von Code bereitgestellten Informationen verarbeiten. Programme, die in der IDE geschrieben werden, werden als Skizzen (Sketches) bezeichnet. Diese Skizzen generieren eine Hex-Datei, die dann auf den Mikrocontroller übertragen und hochgeladen wird.

Die IDE-Umgebung besteht aus zwei Hauptkomponenten: dem Editor und dem Compiler. Der Editor wird zum Schreiben von Code verwendet, während der Compiler den Code kompiliert und auf das Arduino-Modul hochlädt.\cite{ArduinoWeb:2025} In Version 2.3.6 der Arduino IDE spielt die Menüleiste, die sich am oberen Rand der Schnittstelle befindet, eine entscheidende Rolle, da sie Zugriff auf wichtige Befehle wie Hochladen, Verifizieren/Kompilieren und Speichern bietet. Zusätzlich enthält sie das Dateimenü zum Öffnen neuer oder bestehender Dateien sowie den Beispiele-Bereich, der vorgefertigte Skizzen für verschiedene Anwendungen wie Blink und Fade bereitstellt.

Die Arduino IDE 2 ist ein vielseitiges Entwicklungswerkzeug, das Funktionen wie die direkte Installation von Bibliotheken, Cloud-Synchronisation für Sketches und integrierte Debugging-Tools bietet. Dieser Abschnitt beleuchtet einige der Kernfunktionen, mit Verweisen auf detailliertere Ressourcen.

\subsection{Sketchbook}
Das \textbf{Sketchbook} ist der Speicherort für Arduino-Codedateien, die als Sketches bezeichnet werden. Diese Dateien werden mit der Endung \FILE{.ino} gespeichert. Zur ordnungsgemäßen Organisation muss jeder Sketch in einem Ordner abgelegt werden, der genau denselben Namen trägt wie die Sketch-Datei. Beispielsweise muss ein Sketch mit dem Namen \FILE{MySketch.ino} in einem Ordner namens \FILE{MySketch} gespeichert werden. Diese Namenskonvention ist entscheidend, damit die Arduino IDE die Sketches korrekt identifizieren und verwalten kann.

Standardmäßig werden Sketches in einem Ordner namens \FILE{Arduino} gespeichert, der sich im Dokumentenverzeichnis des Systems befindet.

Um auf das Sketchbook zuzugreifen, können Sie das Ordnersymbol in der Seitenleiste der Arduino IDE auswählen. Diese Aktion öffnet das Verzeichnis, in dem die Sketches gespeichert sind, und ermöglicht so eine effiziente Verwaltung und den Zugriff auf die Sketches. \ref{fig:arduinoSketch}

\section{Integration und Verwendung einer benutzerdefinierten Bibliothek in der Arduino IDE}

Bei der Entwicklung eingebetteter Systeme mit der Arduino-Plattform spielen Bibliotheken eine zentrale Rolle, um komplexe Funktionalitäten zu abstrahieren und zu vereinfachen. Eine benutzerdefinierte Bibliothek ist besonders vorteilhaft, wenn bestimmte Funktionen oder Hardware-Schnittstellen in verschiedenen Projekten wiederholt verwendet werden. Dieser Abschnitt beschreibt den Prozess der Erstellung, Installation und Verwendung einer benutzerdefinierten Bibliothek innerhalb eines Arduino-Projekts in der Arduino Integrated Development Environment (IDE).


\subsection{Erstellung der Bibliotheksdateien}

Eine gut strukturierte benutzerdefinierte Arduino-Bibliothek besteht typischerweise aus mindestens zwei Schlüsselkomponenten:

\menu{Header-Datei (.h)}: Diese Datei enthält die Deklarationen von Klassen, Funktionen und Variablen, welche die Schnittstelle der Bibliothek definieren. Sie stellt die notwendigen Definitionen bereit, damit die Funktionen und Klassen von externen Programmen genutzt werden können.

\menu{Quellcode-Datei (.cpp)}: Diese Datei enthält die eigentliche Implementierung der in der Header-Datei deklarierten Funktionen und Methoden. Sie definiert das Verhalten der Funktionen und Klassen.

Die Bibliotheksstruktur ist so organisiert, dass sie eine klare Trennung zwischen Deklaration und Implementierung der Funktionalitäten ermöglicht.


\subsection{Installation und Integration der Bibliothek}

Nach der Erstellung der benutzerdefinierten Bibliothek muss diese korrekt in der Arduino IDE installiert und integriert werden, um in Projekten verwendet werden zu können.

Gehen Sie folgendermaßen vor, um eine benutzerdefinierte Bibliothek in Arduino zu installieren:

\begin{enumerate}
	\item \textbf{Bibliotheksordner lokalisieren}: Die Arduino IDE sucht Bibliotheken im \FILE{Bibliotheken}-Ordner, der sich im Arduino-Sketchbook-Verzeichnis befindet. Der typische Pfad lautet:
	
	\medskip
	
	{\small\SHELL{C:/Benutzer/<Benutzername>/Dokumente/Arduino/Bibliotheken}}
	
	\item \textbf{Bibliothek kopieren}: Kopieren Sie den Ordner der benutzerdefinierten Bibliothek (z.B. \FILE{Nano33BLESenseLED}) in das \FILE{Bibliotheken}-Verzeichnis. Der vollständige Pfad sollte wie folgt aussehen:
	
	\medskip
	
	{\small\SHELL{C:/Benutzer/<Benutzername>/Dokumente/Arduino/Bibliotheken/Nano33BLESenseLED}}
	
	\item \textbf{Arduino IDE neu starten}: Nachdem die Bibliothek im richtigen Verzeichnis platziert wurde, starten Sie die Arduino IDE neu, damit die neue Bibliothek erkannt wird.
	
\end{enumerate}

\subsection{Verwendung symbolischer Links zur Bibliotheksintegration}

In bestimmten Fällen kann es praktischer oder notwendig sein, die Bibliotheksdateien außerhalb des Standard-Bibliotheksverzeichnisses zu speichern. Dies ist beispielsweise sinnvoll, wenn:

\begin{itemize}
	\item Die Bibliotheken in einem GitHub-Repository verwaltet werden
	\item Eine bessere Versionskontrolle benötigt wird
	\item Die Bibliotheken mit mehreren Projekten geteilt werden sollen
\end{itemize}

In solchen Fällen kann der Befehl \menu{mklink} verwendet werden, um einen symbolischen Link zu erstellen. Dieser Link ermöglicht der Arduino IDE den Zugriff auf die Bibliotheksdateien, als wären sie im Standardverzeichnis gespeichert, ohne dass die Dateien tatsächlich dupliziert werden müssen.

\textbf{Vorgehensweise für Windows:}
\begin{enumerate}
	\item Öffnen Sie die Eingabeaufforderung als Administrator
	\item Führen Sie folgenden Befehl aus:
	
	\medskip
	
	\SHELL{mklink /D \\"Pfad im Arduino Verzeichnis"\\"Original Bibliothekspfad"}
	
\end{enumerate}

\bigskip

\textbf{Vorteile dieser Methode:}
\begin{itemize}
	\item Zentrale Verwaltung der Bibliotheksversionen
	\item Keine redundante Speicherung der Dateien
	\item Automatische Synchronisation zwischen Projekten
	\item Einfache Aktualisierung der Bibliotheken
\end{itemize}


\subsection{Windows-Tool \SHELL{mklink} zur Erstellung symbolischer Links}

Symbolische Links ermöglichen die Speicherung von Bibliotheken an einem anderen Ort, während die Arduino IDE sie weiterhin im Standardverzeichnis \FILE{libraries} behandelt. Dies ist besonders nützlich für:

\begin{itemize}
	\item Versionskontrollsysteme wie Git
	\item Organisation von Bibliotheken ohne Dateiduplizierung
	\item Geteilte Bibliotheken zwischen mehreren Projekten
\end{itemize}

\vspace{0.5cm}

\textbf{Schritte zur Erstellung eines symbolischen Links:}

\begin{enumerate}
	\item \textbf{Eingabeaufforderung mit Administratorrechten öffnen:}
	\begin{itemize}
		\item Drücken Sie \menu{Win + S}
		\item Suchen Sie nach \menu{cmd}
		\item Klicken Sie auf \menu{Eingabeaufforderung}
		\item Wählen Sie \menu{Als Administrator ausführen} (siehe Abbildung \ref{fig:cmdLink})
	\end{itemize}
	
	\begin{figure}[H]

\subsection{Überprüfung der Bibliotheksverfügbarkeit in der Arduino IDE}

Um sicherzustellen, dass die benutzerdefinierte Bibliothek erfolgreich integriert wurde und von der Arduino IDE erkannt wird, gehen Sie wie folgt vor:

\begin{enumerate}
	\item \textbf{Arduino IDE neu starten}:
	Falls die IDE während der Installation geöffnet war, schließen und öffnen Sie sie erneut. Dadurch wird die Liste der verfügbaren Bibliotheken aktualisiert.
	
	\item \textbf{Bibliotheksmenü prüfen}:
	Navigieren Sie zu \menu{Sketch} > \menu{Bibliothek einbinden} und wählen Sie die Bibliothek \FILE{Nano33BLESenseLED} aus (siehe Abbildung \ref{fig:arduinoBibliothekEinbinden}).
	
	\item \textbf{Listenpräsenz bestätigen}:
	Erscheint die Bibliothek in der Liste, wurde sie erfolgreich erkannt. Andernfalls überprüfen Sie die Verzeichnisstruktur und den symbolischen Link.
	
	\item \textbf{Testprogramm kompilieren}:
	Erstellen Sie ein einfaches Testprogramm mit Funktionen der Bibliothek. Ein erfolgreicher Kompiliervorgang bestätigt die korrekte Integration.
	
\end{enumerate}

\section{Debugging}

Der Debugger in der Arduino IDE 2.3.6 ist ein leistungsfähiges Werkzeug zur Fehlersuche und Programmoptimierung. Er ermöglicht eine kontrollierte Ausführung des Programmcodes und bietet umfangreiche Analysefunktionen.

\subsection*{Funktionsumfang}
\begin{itemize}
	\item \textbf{Breakpoints}: Markieren Sie bestimmte Codezeilen, an denen die Ausführung automatisch pausieren soll
	\item \textbf{Einzelschrittmodus}: Führen Sie das Programm zeilenweise aus (Step Over/Step Into)
	\item \textbf{Variableninspektion}: Überwachen Sie Werte und Zustände von Variablen in Echtzeit
	\item \textbf{Aufrufstack-Analyse}: Verfolgen Sie den Programmfluss durch verschiedene Funktionsebenen
\end{itemize}
